# L'Agence

L'agence de communication interne d'Evan : 8 agents Claude Code (clientèle, planning stratégique, études, rédaction, direction artistique, social, média, jury) qui travaillent comme les équipes d'une vraie agence, en local sur le Mac.

- Lancer : `npm run agence` (la page des locaux s'ouvre toute seule).
- Tests : `npm test`.
- Qui fait quoi, le circuit, les protections : [docs/equipe.md](docs/equipe.md).
- Les règles suivies par tous les agents : [CLAUDE.md](CLAUDE.md).
- Les projets : `projets/<nom-du-projet>/` (trames vides dans `projets/_modeles/`).

Il faut Node.js (version 20 ou plus) et Claude Code installé et connecté (`claude`).
