# « Let's End Fast Tech » : Back Market, Marcel (2026)

Statut : analyse à partir de la presse et des palmarès. Pas de brief ni de résultats publics trouvés.

## Le brief (ce qui a été demandé)
- **Non trouvé** : brief d'origine absent. Contexte : Back Market vend des appareils reconditionnés. Source : [Brand Innovators](https://brand-innovators.com/cannes-lions-winners-2026/) ; [Contagious](https://www.contagious.com/en/article/cannes-lions-2026-outdoor-winners-34828270d1bd4c11a7f76c203f4af6bd).

## L'insight
- **Fait** : on remplace des appareils qui marchent très bien, chaque année. C'est le cœur de l'argument : la « tech rapide » gaspille. Source : [Brand Innovators](https://brand-innovators.com/cannes-lions-winners-2026/) ; [Contagious](https://www.contagious.com/en/article/cannes-lions-2026-outdoor-winners-34828270d1bd4c11a7f76c203f4af6bd).

## La stratégie
- **Hypothèse** : la marque se positionne contre une habitude de consommation, plutôt que contre un concurrent.

## L'idée créative
- **Fait** : une affiche en extérieur qu'on peut scanner. Source : [Contagious](https://www.contagious.com/en/article/cannes-lions-2026-outdoor-winners-34828270d1bd4c11a7f76c203f4af6bd).

## Le dispositif
- **Fait** : affichage extérieur. Source : même lien.

## Les résultats
- **Non trouvé** : pas de chiffres publics.

## Les récompenses
- **Fait** : Cannes Lions 2026, Gold Outdoor et Gold Challenger Brand. Source : [Brand Innovators](https://brand-innovators.com/cannes-lions-winners-2026/) ; [Contagious](https://www.contagious.com/en/article/cannes-lions-2026-outdoor-winners-34828270d1bd4c11a7f76c203f4af6bd).
- **Fait** : Marcel a obtenu 4 Lions en 2026 au total. Source : [LLLLITL](https://www.llllitl.fr/2026/06/cannes-lions-2026-palmares-france/).

## Ce qu'un agent doit retenir
1. Une marque qui défend une habitude plus durable peut se faire remarquer sans prix.
2. Un support extérieur qui invite à l'action (scanner) évite le simple affichage.
