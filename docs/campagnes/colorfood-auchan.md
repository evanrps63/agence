# « Colorfood » (ou « Le choix des couleurs ») : Auchan, TBWA\Paris (2026)

Statut : analyse à partir de la presse et des palmarès. Les deux noms de campagne sont utilisés selon les sources.

## Le brief (ce qui a été demandé)
- **Fait** : lutter contre le surpoids et l'obésité infantile en donnant envie de bien manger dès le plus jeune âge. Source : [Stratégies](https://www.strategies.fr/actualites/agences/LQ6328811C/cannes-lions-1-un-demarrage-en-douceur-pour-la-france.html).

## L'insight
- **Hypothèse** : les enfants mangent avec les yeux. Les couleurs donnent envie et font le tri entre les familles d'aliments.

## La stratégie
- **Fait** : une approche éducative, construite avec des nutritionnistes et un designer produit. Source : [Stratégies](https://www.strategies.fr/actualites/agences/LQ6328811C/cannes-lions-1-un-demarrage-en-douceur-pour-la-france.html).

## L'idée créative
- **Fait** : six boîtes colorées, une par famille d'aliments, avec des portions adaptées à un repas équilibré. Source : même lien.
- **Fait** : dans un magasin Auchan, un espace de jeu où les enfants composent leur assiette colorée. Source : même lien.

## Le dispositif
- **Fait** : campagne intégrée, avec Havas Media, Zakka Paris, ELSE Paris et EG+ parmi les partenaires. Source : [Reason Why](https://www.reasonwhy.es/media/library/ganadores-health-wellness-cannes-lions-2026.pdf).

## Les résultats (déclarés)
- **Déclaré** : plus de 36 millions de personnes touchées. Chiffre de la marque, non vérifié.

## Les récompenses
- **Fait** : Cannes Lions 2026, Bronze Health & Wellness. Source : [La Réclame](https://lareclame.fr/cannes-lions-2026-palmares-agences-francaises-337100).

## Ce qu'un agent doit retenir
1. Une cause de santé peut être traduite en objet concret et en jeu.
2. Un code visuel (les couleurs) peut faire le travail éducatif.

## DA à analyser (à compléter avec Léa)
Palette des six familles, forme des boîtes, graphisme du magasin : à relever sur les visuels.
