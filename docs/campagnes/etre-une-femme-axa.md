# « Être une femme ne devrait jamais être un risque » : AXA, Publicis Conseil et WPP Media (2023-2025)

Statut : analyse à partir de la fiche Effie et de la presse. Les chiffres sont ceux déclarés dans la fiche de candidature.

## Le brief (ce qui a été demandé)
- **Fait** : AXA était connue, mais pas choisie. D'après Effie, 38 % des Français connaissaient la marque sans la considérer. Objectif : être dans le top 3 de l'image positive, de la considération et de l'intention d'achat. Source : [Effie](https://www.effie.fr/prix/etre-une-femme-ne-devrait-jamais-etre-un-risque-proteger-ce-qui-compte-comment-axa-a-conquis-le-coeur-des-francais/).

## L'insight
- **Fait** : le film met en scène les femmes sous-protégées et trop exposées aux risques. Source : [CB News](https://www.cbnews.fr/marques/image-fait-etre-femme-ne-devrait-jamais-etre-risque-axa-80529).
- **Hypothèse** : le problème est moins la marque que sa place dans l'imaginaire. Une assurance parle de risques : il fallait lui faire parler de protection.

## La stratégie
- **Fait (déclaré)** : une stratégie de marque sur trois ans. Source : [Effie](https://www.effie.fr/prix/etre-une-femme-ne-devrait-jamais-etre-un-risque-proteger-ce-qui-compte-comment-axa-a-conquis-le-coeur-des-francais/).

## L'idée créative
- **Fait** : un film de 1 min 45, réalisé par Madeline Clayton, sur les femmes peu protégées et trop exposées. Source : [CB News](https://www.cbnews.fr/marques/image-fait-etre-femme-ne-devrait-jamais-etre-risque-axa-80529).

## Le dispositif
- **Fait** : Publicis Conseil (création) et WPP Media (achat). Source : [Effie](https://www.effie.fr/prix/etre-une-femme-ne-devrait-jamais-etre-un-risque-proteger-ce-qui-compte-comment-axa-a-conquis-le-coeur-des-francais/).

## Les résultats (déclarés)
- **Déclaré** : AXA devient l'assureur préféré des Français en trois ans. Source : [The Media Leader](https://fr.themedialeader.com/effie-france-2025-havas-play-publicis-media-luxe-havas-paris-et-prose-on-pixels-remportent-le-grand-prix/).
- **À vérifier** : les deux sources ne donnent pas le même classement exact (image, considération, intention). La fiche Effie est la référence.

## Les récompenses
- **Fait** : Effie France 2025, Or dans la catégorie « Efficacité dans la durée ». Source : [Effie](https://www.effie.fr/prix/etre-une-femme-ne-devrait-jamais-etre-un-risque-proteger-ce-qui-compte-comment-axa-a-conquis-le-coeur-des-francais/).

## Ce qu'un agent doit retenir
1. Une marque connue mais pas choisie : le problème est le choix, pas la notoriété.
2. Trois ans de continuité : une campagne d'image peut prouver son effet sur la durée.
3. Le même sujet peut mener à une action concrète (voir la fiche Three Words).
