# « The partnership that changed everything » : LVMH, Havas Play et partenaires (2024-2025)

Statut : analyse à partir de la presse spécialisée. Le dossier Effie complet n'a pas été lu.

## Le brief (ce qui a été demandé)
- **Fait** : LVMH devenait partenaire des Jeux. Les règles olympiques limitent la visibilité des marques dans les lieux et les cérémonies. Source : [Contagious](https://www.contagious.com/news-and-views/cannes-lions-2025-luxury-winners).
- **Fait** : sans médias traditionnels autorisés, il fallait créer un contenu que les médias veulent couvrir et que le public veut partager. Même source.

## L'insight
- **Hypothèse** : un groupe de luxe est perçu comme loin du sport. Le partenariat devait prouver sa légitimité dans le sport.
- **Fait (déclaré)** : la légitimité sport a progressé de 14 points. Source : [The Media Leader](https://fr.themedialeader.com/effie-france-2025-havas-play-publicis-media-luxe-havas-paris-et-prose-on-pixels-remportent-le-grand-prix/). Chiffre à vérifier dans le dossier Effie.

## La stratégie
- **Fait** : passer de sponsor à co-producteur des Jeux. Source : [Contagious](https://www.contagious.com/news-and-views/cannes-lions-2025-luxury-winners).
- **Fait** : l'idée centrale, « Artisans de toutes les victoires », met en avant les métiers (les artisans) qui ont fait les tenues et les accessoires. Source : [The Media Leader](https://fr.themedialeader.com/effie-france-2025-havas-play-publicis-media-luxe-havas-paris-et-prose-on-pixels-remportent-le-grand-prix/).
- **Hypothèse** : la stratégie vise la fierté d'un savoir-faire plutôt que la vente de produits. C'est la leçon principale pour le luxe.

## L'idée créative et le dispositif
- **Fait** : des marques du groupe (Dior, Berluti, Louis Vuitton, Chaumet) ont créé des tenues et des accessoires pour les cérémonies. Source : [Contagious](https://www.contagious.com/news-and-views/cannes-lions-2025-luxury-winners).
- **Fait** : contenu conçu pour être repris par la presse et partagé. Source : même lien.

## Les résultats (déclarés)
- **Déclaré** : +10 points de perception positive, +14 points de légitimité sport, en 9 mois. Source : [The Media Leader](https://fr.themedialeader.com/effie-france-2025-havas-play-publicis-media-luxe-havas-paris-et-prose-on-pixels-remportent-le-grand-prix/), [Packshotmag](https://www.packshotmag.com/2025/12/09/effie-france-2025-lvmh-remporte-le-grand-prix-buzzman-est-confirmee-agence-effie-france-de-lannee/).

## Les récompenses
- **Fait** : Effie France 2025, Grand Prix. Source : [CB News](https://www.cbnews.fr/conseil/campagne-the-partnership-that-changed-everything-lvmh-remporte-grand-prix-effie-2025).
- **Fait** : Cannes Lions 2025, Grand Prix Luxury & Lifestyle.

## Ce qu'un agent doit retenir
1. Une marque qui n'a pas le droit de se montrer peut se rendre utile à l'événement.
2. Le savoir-faire (les artisans) peut devenir le héros du message.
3. Mesurer la légitimité, pas seulement la notoriété.
