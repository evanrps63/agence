# « The Trojan Fax » : IUCN Comité français, Fujifilm, BETC Paris (2026)

Statut : analyse à partir de deux agrégateurs de prix. Peu de sources primaires. Les chiffres de conversion viennent d'un site secondaire.

## Le brief (ce qui a été demandé)
- **Non trouvé** : brief d'origine absent. Contexte : promouvoir l'inscription des territoires à la certification « Liste verte » de la biodiversité. Source : [unblock.coffee](https://www.unblock.coffee/campaign/the-trojan-fax/).

## L'insight
- **Hypothèse** : les élus locaux reçoivent des emails qu'ils ne lisent pas. Un objet inattendu, qui se lit, attire l'attention.

## La stratégie
- **Fait** : cibler les maires français, par un canal peu utilisé. Source : [unblock.coffee](https://www.unblock.coffee/campaign/the-trojan-fax/).

## L'idée créative
- **Fait** : des fax en art ASCII envoyés aux maires pour les inviter à s'inscrire. Source : même lien.
- **Intuition** : le fax est un objet d'époque, il devient une surprise. C'est le médium qui fait le message.

## Le dispositif
- **Fait** : envoi postal ou fax, ciblé. Print & Publishing dans les catégories des prix. Source : [Brand Innovators](https://brand-innovators.com/cannes-lions-winners-2026/).

## Les résultats (déclarés, à vérifier)
- **À vérifier** : taux de conversion de 26 % contre 2,3 % pour l'email. Source unique, site secondaire. Ne pas citer sans vérifier auprès de l'IUCN.

## Les récompenses
- **Fait** : Cannes Lions 2026, Gold Print & Publishing (usage innovant et adapté). Source : [Brand Innovators](https://brand-innovators.com/cannes-lions-winners-2026/).
- **À vérifier** : Argent. Une source le classe en Creative B2B, une autre en Targeting & Engagement. Source : [LLLLITL](https://www.llllitl.fr/2026/06/cannes-lions-2026-palmares-france/).

## Ce qu'un agent doit retenir
1. Un média désuet peut devenir la surprise, si l'objet est en rapport avec le message.
2. La cible (les maires) est petite : une campagne ciblée peut être très efficace.
3. Les chiffres de conversion sont à vérifier avant de les utiliser.

## DA à analyser (à compléter avec Léa)
Art ASCII, police du fax, mise en page du courrier : à relever sur les visuels.
