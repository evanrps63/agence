# « On s'habitue vite à la classe Ulys » : Vinci Autoroutes, Buzzman et Havas Media France (2024 ; campagne de 2023)

Statut : analyse à partir du palmarès Effie et de la presse. Les chiffres datent de 2023.

## Le brief (ce qui a été demandé)
- **Fait** : Ulys, le badge de télépéage, voulait se différencier d'un service jugé sans émotion. Source : [Influencia](https://www.influencia.net/grand-prix-effie-2024-les-tendances-des-campagnes-recompensees-et-la-victoire-de-vinci-autoroutes-avec-on-shabitue-vite-a-la-classe-ulys-buzzman-et-havas-media/).

## L'insight
- **Fait (presse)** : le plaisir de passer devant tout le monde au péage. Le badge rend ce plaisir possible. Source : [La Réclame](https://lareclame.fr/effie-awards-france-2024-union-des-marques-buzzman-ulys-resultats-306896).
- **Intuition** : l'insight est un plaisir coupable. Il se teste bien sur un public qui fait la file.

## La stratégie
- **Fait** : donner une dimension émotionnelle à un service pratique, par l'humour. Source : [Influencia](https://www.influencia.net/grand-prix-effie-2024-les-tendances-des-campagnes-recompensees-et-la-victoire-de-vinci-autoroutes-avec-on-shabitue-vite-a-la-classe-ulys-buzzman-et-havas-media/).

## L'idée créative
- **Fait** : le ton est humoristique, et la phrase « on s'habitue vite » suggère l'habitude d'un privilège. Source : [LLLLITL](https://www.llllitl.fr/2024/11/effie-awards-france-2024/).
- **Hypothèse** : la force de l'idée est de transformer un gain de temps en fierté.

## Le dispositif
- **Fait** : télévision, affichage, digital et radio, achetés par Havas Media France. Source : [La Réclame](https://lareclame.fr/effie-awards-france-2024-union-des-marques-buzzman-ulys-resultats-306896).

## Les résultats (déclarés, données de 2023)
- **Déclaré** : +30 % de ventes de badges, +23 points de notoriété. Sources : YouGov et interne, cités par [Influencia](https://www.influencia.net/grand-prix-effie-2024-les-tendances-des-campagnes-recompensees-et-la-victoire-de-vinci-autoroutes-avec-on-shabitue-vite-a-la-classe-ulys-buzzman-et-havas-media/).

## Les récompenses
- **Fait** : Effie France 2024, Grand Prix. Source : [AACC, communiqué](https://www.aacc.fr/wp-content/uploads/2024/11/CdP_PalmaresEffie2024.pdf).
- **Fait** : 4e Grand Prix de Buzzman en dix ans. Source : [La Réclame](https://lareclame.fr/effie-awards-france-2024-union-des-marques-buzzman-ulys-resultats-306896).

## Ce qu'un agent doit retenir
1. Un service utilitaire peut être vendu par le plaisir.
2. Un effet mesurable (ventes, notoriété) rend l'idée défendable.
3. Une campagne de 2023 reste une référence, mais ses chiffres sont anciens : le dire.

## Ce qui manque
