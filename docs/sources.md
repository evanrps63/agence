# Bibliothèque des sources vérifiées

Les sources que l'agence a vérifiées une fois, et qu'elle peut réutiliser dans tous les projets. Inès part de cette liste avant de chercher sur le web.

Une source ne s'ajoute ici qu'après ta validation : tu as ouvert le lien, et le chiffre est bien dans le document.

Format, une ligne par source :
`- Chiffre ou fait, tel qu'il est écrit | Organisme ou auteur, « titre », année | lien | vérifié le AAAA-MM-JJ`
