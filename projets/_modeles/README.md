# Les trames de l'agence

Chaque fichier ici est un modèle vide. Les agents reprennent le même titre de section pour que tu retrouves toujours les mêmes parties.

| Trame | Qui la remplit | Quand |
|---|---|---|
| `brief.md` | Claire | Dès que tu donnes un brief |
| `insights.md` | Inès, Max | Après le brief |
| `strategie.md` | Max | Après les insights |
| `idee-creative.md` | Hugo, Léa | Une fois la piste choisie |
| `dispositif-social.md` | Sam | Après l'idée créative |
| `dispositif-media.md` | Nora | Après l'idée créative |
| `relecture.md` | Le Jury | Avant tout livrable final |
| `storyboard-video.md` | Nino | Quand Evan veut une vidéo |
| `reco.md` | Max, avec l'équipe | Une fois le circuit terminé |
| `fiche-travail-cours.md` | Claire, pour un projet de cours | Au début d'un cours |
| `consignes-prof.md` | Toi | Dès que tu as la grille du prof (créée toute seule pour un cours) |
| `projet.json` | L'agence | Créé avec le brief (nom, type, date) |

Un fichier de projet se reconnaît à son nom : il doit être court, en minuscules, sans accent. Les trames ne sont jamais modifiées par l'agence.
